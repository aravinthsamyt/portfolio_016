# Aravinthsamy — Fullstack Developer Portfolio (HTML/CSS/JS)

Pure static version of the portfolio. No frameworks, no build step.

## Run
Just open `index.html` in a browser, or serve locally:
```bash
npx serve .
# or
python3 -m http.server 8000
```

## Files
- `index.html` — markup
- `styles.css` — design tokens, dark/light theme, responsive layout
- `script.js` — theme toggle, smooth scroll, typewriter, animated skill rings, scroll reveal, project cards, contact form
- `assets/` — profile + project images

## Features
- Dark/light theme with localStorage persistence
- Sticky glass navbar with animated underline + active section highlight
- Hero with typewriter effect and floating image
- Animated circular skill bars (fill on scroll)
- Project cards with hover scale, shadow, and reveal buttons
- Smooth scroll + fade/slide reveal animations
- Fully responsive
